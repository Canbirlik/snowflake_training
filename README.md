# Snowflake Training & Practice

A personal learning repository for Snowflake concepts, SQL exercises, platform administration, and hands-on practice.

## Repository contents

- `Assignments/` — practice assignments
- `Module-2/` — module-based learning materials

## Working locally

1. Create a dedicated Python virtual environment on your machine.
2. Install only the dependencies required by the scripts you intend to run.
3. Keep account identifiers, passwords, private keys, API tokens, and company/customer data outside the repository. Use environment variables or a local, untracked configuration file.

## Security

- Never commit credentials, private keys, account-specific connection details, or customer/company data.
- Rotate any credential immediately if it was ever committed.
- This repository is for learning and practice, not a production deployment.

## Attribution

Exercises and examples may be based on external training material. Refer to individual folders and files for their context and attribution.
